# Bass Scale Quest

Mobile-first bass scale learning prototype. Upload `index.html` to a public GitHub repository and enable GitHub Pages (Settings → Pages → Deploy from branch → main / root). Open the HTTPS site on Android Chrome and allow microphone access.

Features: complete major-key chart, major/pentatonic/major-blues/minor-blues note maps, printable chart, fretboard, pitch-class microphone practice, local XP. Prototype note recognition may be unreliable on very low bass notes or in noisy environments. No audio is uploaded or recorded.
